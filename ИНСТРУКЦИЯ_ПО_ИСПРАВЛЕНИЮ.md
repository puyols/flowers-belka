   - Логин: `puyols`

2. **Перейдите в раздел "WWW" → "WWW-домены"**

3. **Найдите домен `flowers-belka.ru` и нажмите "Изменить"**

4. **Включите опции:**
   - ✅ SSL (должен быть уже включен)
   - ✅ **"Перенаправлять HTTP на HTTPS"** ← ЭТО ГЛАВНОЕ!

5. **Сохраните изменения**

#### Альтернативный способ (через .htaccess):

Если в панели нет нужной опции, создайте/отредактируйте файл `.htaccess` в корне сайта:

```apache
# Принудительное перенаправление на HTTPS
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

# Дополнительные настройки безопасности
Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"
```

**Где находится файл:**
- FTP путь: `/var/www/s184498/data/flowers-belka.ru/.htaccess`
- Создайте файл, если его нет

**Проверка:**
После настройки проверьте:
- `http://flowers-belka.ru` → должен редиректить на `https://flowers-belka.ru`
- `https://flowers-belka.ru/catalog` → НЕ должен редиректить на главную

### 3. Регистрация в поисковых системах

**Проблема:** Сайт не верифицирован в Google/Яндекс/Bing

#### Google Search Console:

1. Перейдите: https://search.google.com/search-console
2. Добавьте сайт `https://flowers-belka.ru`
3. Выберите способ подтверждения "HTML-тег"
4. Скопируйте код вида: `google1234567890abcdef.html`
5. В файле `layout.tsx` раскомментируйте и вставьте код:

```typescript
verification: {
  google: 'ваш-код-от-google',
  yandex: 'ваш-код-от-яндекса',
  other: {
    'msvalidate.01': 'ваш-код-от-bing'
  }
}
```

#### Яндекс.Вебмастер:

1. Перейдите: https://webmaster.yandex.ru/
2. Добавьте сайт `https://flowers-belka.ru`
3. Выберите способ подтверждения "Мета-тег"
4. Скопируйте код из мета-тега
5. Вставьте в `layout.tsx` (см. выше)

#### Bing Webmaster:

1. Перейдите: https://www.bing.com/webmasters
2. Добавьте сайт
3. Получите код верификации
4. Вставьте в `layout.tsx` (см. выше)

**После верификации:**
- Отправьте sitemap.xml в каждую из систем
- URL: `https://flowers-belka.ru/sitemap.xml`
